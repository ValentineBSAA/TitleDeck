# Install TitleDeck 1.1.8

**Latest public release:** [TitleDeck 1.1.8](https://github.com/ValentineBSAA/TitleDeck/releases/tag/1.1.8).

1. Use a Valve **Steam Deck in SteamOS Gaming Mode** with Decky Loader installed.
2. Download **[TitleDeck-1.1.8.zip](https://github.com/ValentineBSAA/TitleDeck/releases/download/1.1.8/TitleDeck-1.1.8.zip)**.
3. **Do not extract** the installer ZIP. Screenshots are separate images and are not a plugin installer.
4. Press **••• → Decky Loader plug icon → Decky Settings → Developer → Install Plugin from ZIP**. Select the downloaded installer. Menu wording may differ by Decky version.
5. Return to **Quick Access → Decky → TitleDeck** and confirm the version badge.
6. Choose **Open Full Library Manager**. Use **⚙ Settings** inside the manager for theme, backups, description placement, hidden cards and restoration.

**Updating:** create a manual title backup before large upgrades, then install the replacement ZIP. Don't delete existing customization settings unless deliberately restoring originals.

**After installing:** test a saved name, Steam/non-Steam Game Info description and LB/RB paging. Steam Game Info descriptions **scroll with an external controller's right stick**, but **not with the Steam Deck's built-in right stick** in 1.1.8 ([issue #8](https://github.com/ValentineBSAA/TitleDeck/issues/8)).

The primary verified target is the Steam Deck in Gaming Mode. Other handhelds, Steam Desktop Mode, Windows and Android are unverified.
