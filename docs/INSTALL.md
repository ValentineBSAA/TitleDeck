# Install TitleDeck 1.2.2 Stable

> **Published stable release:** [TitleDeck 1.2.2](https://github.com/ValentineBSAA/TitleDeck/releases/tag/1.2.2). Download the genuine `TitleDeck-1.2.2-Stable.zip` asset from this release. Keep the ZIP intact for Decky Loader.

**Latest public release:** [TitleDeck 1.2.2](https://github.com/ValentineBSAA/TitleDeck/releases/tag/1.2.2).

1. Use a Valve **Steam Deck in SteamOS Gaming Mode** with Decky Loader installed.
2. Download **[TitleDeck-1.2.2-Stable.zip](https://github.com/ValentineBSAA/TitleDeck/releases/download/1.2.2/TitleDeck-1.2.2-Stable.zip)**.
3. **Do not extract** the installer ZIP. Screenshots are separate images and are not a plugin installer.
4. Press **••• → Decky Loader plug icon → Decky Settings → Developer → Install Plugin from ZIP**. Select the downloaded installer. Menu wording may differ by Decky version.
5. Return to **Quick Access → Decky → TitleDeck** and confirm the version badge.
6. Choose **Open Full Library Manager**. Use **⚙ Settings** inside the manager for theme, backups, description placement, hidden cards and restoration.

**Updating:** create a manual title backup before large upgrades, then install the replacement ZIP. Don't delete existing customization settings unless deliberately restoring originals.

**New in 1.2.2:** I added my own **ValentineBSAA** GitHub logo beneath **Open Full Library Manager** in Quick Access. Press **A** while it is focused (or tap it) to visit [my GitHub profile](https://github.com/ValentineBSAA). I tested the link on my Steam Deck. Thanks for giving TitleDeck a try!

**After installing:** test a saved name, Steam/non-Steam Game Info description, LB/RB paging, **Options (☰) → Edit with TitleDeck**, STEAM-button alias toggle, and **650 ms hold B/Circle quick exit**. Steam Game Info descriptions **scroll with an external controller's right stick**, but **not with the Steam Deck's built-in right stick** in 1.2.2 ([issue #8](https://github.com/ValentineBSAA/TitleDeck/issues/8)).

The primary verified target is the Steam Deck in Gaming Mode. Other handhelds, Steam Desktop Mode, Windows and Android are unverified.
