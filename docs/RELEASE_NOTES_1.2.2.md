# TitleDeck 1.2.2 Stable 🌸

**Your library. Your names. Your descriptions. Now with a visible creator credit.**

TitleDeck 1.2.2 is a small, hardware-tested quality-of-life update. It adds a controller-focusable developer link to Quick Access without changing the established game editing features.

## What's new

- **ValentineBSAA GitHub button:** a tasteful circular developer-avatar button appears directly beneath **Open full library manager** in TitleDeck's Quick Access panel.
- **Controller friendly:** focus the button with the Steam Deck controls and press **A** to visit the developer's GitHub profile.
- **Steam-native navigation:** opens the GitHub page using Steam's external-web navigation when available, with additional fallbacks.
- **Offline fallback:** if the remote avatar can't load, a crimson V appears instead of a broken image.
- **Same TitleDeck features:** game title aliases, Game Info descriptions, Steam and non-Steam support, native Options menu editing, backups, restoration, and controller navigation remain unchanged.

## Verified on hardware

The creator installed TitleDeck **1.2.2** on a physical Steam Deck and confirmed the new GitHub button works and opens the correct developer profile.

The previously accepted **1.2.1** library features carry forward unchanged. This update makes no claim to repair unrelated compatibility issues.

**Known limitation:** Steam Deck's built-in right stick still has a tracked Game Info custom-description scrolling issue; see [issue #8](https://github.com/ValentineBSAA/TitleDeck/issues/8). External-controller scrolling was previously confirmed.

## Install or update

Download **TitleDeck-1.2.2-Stable.zip** from the assets section of this release. Do not install GitHub's automatically generated source-code ZIP.

Use **Decky Loader → Settings → Developer → Install Plugin from ZIP** and select the named TitleDeck ZIP.
