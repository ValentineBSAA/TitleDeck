# TitleDeck 1.2.2 Stable 🌸

**Your library. Your names. Your descriptions.**

For 1.2.2, I wanted to make one small change that means a lot to me. I've added **my own GitHub profile logo** to TitleDeck's Quick Access menu. It's a simple, controller-friendly way to see who created the plugin and find my other projects if you're curious.

TitleDeck started with an idea from the Steam Deck community: let people choose how their game titles appear. More suggestions followed, including the ability to write custom Game Info descriptions. I took those ideas and kept building and testing until TitleDeck became the library customization tool I wanted to use myself.

I appreciate everyone who's given it a chance. Whether you've downloaded it, tested a new version, reported an issue, shared an idea, or just quietly used it to make your library feel a little more like yours, **thank you**. I don't take that support for granted.

## What's new in 1.2.2

- **My developer logo in Quick Access:** My circular GitHub avatar and **ValentineBSAA** name now appear in a button below **Open full library manager**.
- **One-button GitHub link:** Focus **View developer on GitHub ↗** using the D-pad and press **A**, or select it with touch, to open [my GitHub profile](https://github.com/ValentineBSAA).
- **Steam-friendly navigation:** The link uses Steam's external-web navigation where available, with fallbacks if needed.
- **Offline appearance:** If the avatar can't load, a crimson V is shown instead of a broken image.

That's the entire point of this update: a little developer credit, not a new obstacle between you and your games. There are no new steps you have to go through to use TitleDeck.

## What hasn't changed

Everything from 1.2.1 is still here: local Steam and non-Steam game renaming, custom descriptions, the Full Library Manager, backups and restoration, the native **Options → Edit with TitleDeck** shortcut, STEAM-button menu title aliases, and the **650 ms B/Circle hold** for leaving a context-launched editor.

Your custom names and descriptions stay local. TitleDeck does not modify installed game files or Valve's original game metadata.

## Tested on my Steam Deck

I installed **1.2.2** on my physical Steam Deck and confirmed the new GitHub button opens the right profile. The previous 1.2.1 library features carry forward unchanged. That test doesn't mean I've verified every SteamOS version, theme, or controller.

**Known limitation:** The Deck's built-in right stick still has a tracked scrolling issue inside custom **Game Info** descriptions; an external controller's right stick works in the tested cases. I haven't claimed a fix for that in 1.2.2. See [issue #8](https://github.com/ValentineBSAA/TitleDeck/issues/8).

## Install or update

Download **[TitleDeck-1.2.2-Stable.zip](https://github.com/ValentineBSAA/TitleDeck/releases/download/1.2.2/TitleDeck-1.2.2-Stable.zip)** from the release assets. Leave the ZIP intact and install it through **Decky Loader → Settings → Developer → Install Plugin from ZIP**. GitHub's automatically generated source-code ZIP is *not* the Decky installer.
