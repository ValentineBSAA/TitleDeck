# TitleDeck beginner's guide (redirect)

> **Current stable release: [TitleDeck 1.2.1](https://github.com/ValentineBSAA/TitleDeck/releases/tag/1.2.1).**

This older `BEGINNERS_GUIDE.md` path is retained so existing bookmarks and links still work. To avoid conflicting instructions, all current step-by-step documentation is maintained in **[the complete illustrated 1.2.1 beginner guide](BEGINNER_GUIDE.md)**.

The complete guide covers installing/updating, Steam and non-Steam title edits, custom Game Info descriptions, saving/restoring, the Full Library Manager, keyboard and controller navigation, backups, hidden tiles, every Settings section, and all **23 actual Steam Deck screenshots**.

**Known limitation (also present in 1.2.1):** the right stick currently does not reliably scroll custom text within Steam's Game Info description areas for either Steam or non-Steam games. This is separate from successful saved-description rendering and reboot persistence. See [issue #8](https://github.com/ValentineBSAA/TitleDeck/issues/8).
