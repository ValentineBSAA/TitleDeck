# TitleDeck 0.9.0 RC release notes

This earlier draft release-notes page has been superseded by the **[published TitleDeck 0.9.0 RC1 release notes](RELEASE_NOTES_0.9.0_RC1.md)**.

The existing public release is [TitleDeck 0.9.0 RC1](https://github.com/ValentineBSAA/TitleDeck/releases/tag/0.9.0), with installer **`TitleDeck-0.9.0-RC1-SteamDeck.zip`**, internal plugin version **`0.9.0-rc.1`**, and unchanged known Steam keyboard dismissal limitation.

Compatibility is currently verified only for selected features on a physical Valve Steam Deck in Gaming Mode. Other hardware and SteamOS-like distributions remain unverified.
