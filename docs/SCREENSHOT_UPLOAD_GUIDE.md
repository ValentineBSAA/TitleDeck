# Adding TitleDeck 1.1.8 screenshots

**For the maintainer:** This repository is already prepared for your new screenshots, but there is **no new screenshot ZIP release asset** planned.

## When you send the screenshot ZIP

1. Extract the photos **locally for review**; do not commit the original `screenshots.zip` to the repository.
2. Choose clear images that show the actual **1.1.8** UI and do not expose private account details.
3. Add only the selected individual images under `docs/screenshots/v1.1.8/`, with descriptive names such as:
   - `01-titledeck-quick-access.jpeg`
   - `02-full-library-manager.jpeg`
   - `03-steam-game-info.jpeg`
   - `04-non-steam-game-info.jpeg`
   - `05-title-editor.jpeg`
   - `06-settings-and-color-picker.jpeg`
4. Keep authentic screenshot contents intact; crop only if specifically approved, and preserve original quality whenever practical.
5. Add verified images to [SCREENSHOTS.md](SCREENSHOTS.md), then feature selected images in the main [README](../README.md).
6. Do **not** claim a screenshot demonstrates Game Info right-stick scrolling, which remains an issue in the current candidate.
7. Keep earlier `v0.8.1`, `v0.9.0-rc1` and `v0.9.2-beta1` captures in their historical locations.

## How GitHub users should encounter them

The README and gallery link to **individual screenshots in the repository**. The public Releases page will ultimately have only the **TitleDeck plugin installer ZIP**, not a screenshot ZIP. The old historic release assets remain untouched.
