# TitleDeck 1.4.0 feature guide
[← Home](../README.md) · [Beginner guide](BEGINNER_GUIDE.md) · [Screenshots](SCREENSHOTS.md) · [Upgrade comparison](UPDATE_FROM_1.2.2.md)

## Library titles and descriptions
TitleDeck lets you give Steam and non-Steam games locally displayed titles and custom Game Info descriptions without changing installed game files or the original Steam metadata. Restore originals when you want. A native game Options shortcut can open the relevant editor directly.

## Full Library Manager
Browse Steam and non-Steam games, search by name or App ID, filter entries and edit their labels or descriptions in one place. The 1.4.0 interface has improved artwork placeholders/transitions, more consistent tab layout, controller navigation and LB/RB movement. Advanced and recovery options help locate hidden entries and undo local changes.

## Typography Studio
Customize Home title styling with 10 presets based on available fonts, custom colors (including HEX/RGB input, hue and shade), optional outlines, shadows, glow, and light/dark contrast guidance. The contrast indicator **informs** your choice; it does not silently overwrite your selected color. Custom ZIP/TTF font importing is **not supported** in 1.4.0.

## Steam Home position and Art Hero
With Art Hero absent or off, TitleDeck's Above Cards/Below Cards settings and saved offsets control its own title presentation. With Art Hero enabled, TitleDeck reads and displays the Carousel Font Height/Above–Below state but intentionally disables the buttons; use **CSS Loader → Art Hero** to change the actual setting. [Details](ART_HERO_COMPATIBILITY.md).

## Quick Access, backup and restore
Open the manager quickly from Decky, access display options and follow the developer's profile link. Backups, restoring original names and recovery tools help you keep changes reversible.

## What to know
This plugin targets **Steam Deck Gaming Mode with Decky Loader**. Theme interactions vary. The built-in Deck stick Game Info scrolling issue remains open ([#8](https://github.com/ValentineBSAA/TitleDeck/issues/8)); an earlier Quick Access focus quirk is not listed as resolved.
