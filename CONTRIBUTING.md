# Contributing to TitleDeck

Thank you for improving TitleDeck. Keep its central purpose simple: reliable, reversible **Steam Deck display title customization**.

- Use [Issues](https://github.com/ValentineBSAA/TitleDeck/issues) for reproducible bugs and [Discussions](https://github.com/ValentineBSAA/TitleDeck/discussions) for ideas and questions.
- Do not replace the local display alias design with game-file or Steam metadata edits.
- Preserve existing aliases, backups, the restore safety checks and settings compatibility.
- Test controller **Up/Down/Left/Right**, especially focus near borders, scrolling and disabled controls.
- Verify compact handheld layouts and CSS Loader themes.
- Run the tests described in [SOURCE.md](SOURCE.md).
- Clearly identify device-tested observations versus simulated test coverage.

Screenshots must not expose private account information. The repository is MIT licensed.
