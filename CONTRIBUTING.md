# Contributing to TitleDeck

TitleDeck focuses on **Steam Deck Gaming Mode** and maintaining reliable, reversible displayed-title aliases.

- Use [Discussions](https://github.com/ValentineBSAA/TitleDeck/discussions) for questions and [Issues](https://github.com/ValentineBSAA/TitleDeck/issues) for actionable bugs.
- **Record physical hardware** in test reports. ROG Ally, other SteamOS-like handhelds, Desktop Mode, Windows and Android/DroidDeck are **untested and not an RC1 support commitment**.
- Preserve aliases, saved backups, non-destructive cleanup previews and explicit Save.
- Keep title cleanup safe for Unicode Greek Σ, Roman numerals and mixed-case words.
- Test Left, Right, Up and Down in the library, editor and confirmation dialogs.
- Do not modify installed games, Steam's sorting identity or game art.
- Run Node and Python regression tests and clearly separate hardware-verified features from automated-only results.
- Do not claim B keyboard dismissal is consistently fixed until real-device testing supports it.
