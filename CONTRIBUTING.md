# Contributing to TitleDeck

TitleDeck's goal is small and deliberate: **locally saved, reversible Steam game display-name customization in Valve Steam Deck Gaming Mode**. It does not edit game files, Steam canonical sorting metadata or artwork.

> **Compatibility warning:** TitleDeck is developed and device-tested on a **physical Valve Steam Deck running SteamOS Gaming Mode with Decky Loader**. **ROG Ally, other handheld PCs, third-party SteamOS installations or derivatives, Windows, Android/DroidDeck, and Desktop Mode are not verified or officially supported.** The interface, Decky integration, controller focus, and Steam keyboard may behave differently or fail on those systems.

Discuss suggestions in [Discussions](https://github.com/ValentineBSAA/TitleDeck/discussions), report reproducible bugs in [Issues](https://github.com/ValentineBSAA/TitleDeck/issues/new/choose). Include device model/OS, Steam/Decky versions, controller direction sequence and any CSS Loader theme.

Please preserve saved aliases/backup compatibility, keep cleanup suggestions explicit and reversible, and test both keyboard B dismissal and RT/Enter paths. Run the frontend/backend automated suites, but distinguish simulated tests from physical Steam Deck results. Windows, Android, ROG Ally and other SteamOS devices are welcome as experimental community reports, not guaranteed platforms.

MIT licensed. Screenshots must not expose personal data.
