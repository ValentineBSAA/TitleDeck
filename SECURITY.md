# Security policy

TitleDeck 0.8.1 is a Steam Deck community prerelease. No formal security bounty or response-time commitment is offered.

For sensitive concerns, do **not** post account secrets, authentication codes or vulnerable device information in a public issue. Use private vulnerability reporting if it is available in the repository's Security tab or reach the project maintainer privately through an established channel.

TitleDeck should never require a Steam password, Steam Guard code, game-file modification, or unrelated credential access. For non-sensitive issues use [GitHub Issues](https://github.com/ValentineBSAA/TitleDeck/issues).
